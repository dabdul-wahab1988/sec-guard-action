# Security Policy

Please do not disclose credentials, private keys, or other sensitive material in a public issue or pull request.

Use [GitHub private vulnerability reporting](https://github.com/dabdul-wahab1988/sec-guard-action/security/advisories/new) for security reports. Include a reproducible description, the affected commit or release, and the minimum evidence needed to reproduce the issue.

The action may send bounded, redacted remediation context to OpenAI when `openai_api_key` is configured. Report any suspected secret-handling or prompt-boundary issue through the private channel first.

## Supported versions

| Version | Supported |
| --- | --- |
| `v1.x` | Yes, after the corresponding release tag is published |
| `main` | Development only |
